                              Your first conversation
                              
  
                              Switchboard connects your AI model to a project on this computer.
                              
  
                                
    
                              1. Connect a model
                                Open Settings → Models to add a provider (Base URL, protocol, API key), then fetch or add models and pick a default. The API key stays on this computer. Advanced setups can still edit the llm block in switchboard.config.jsonc and restart sbx web.
                                2. 
    
                              2. Choose your project
                                Use the folder button above the composer to pick a workspace. File and command tools use this folder.
                                3. 
    
                              3. Tell it what you need
                                Choose a model, write a message, and press Enter. Try one of the examples first. Use @ to reference a file and / for commands.
                                4. 
  
                              
  
                              Want to review changes before they run? Set approval.mode to risky or all in your configuration. With off, tools run without asking.
