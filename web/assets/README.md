# BotConnector brand assets

Original assets supplied by the BotConnector owner (see `NOTICE`: not MIT-licensed).

- `bico-hero.png`: original transparent 335×455 Bico hero. Use on light
  surfaces only; do not upscale beyond the original resolution.
- `bico-mark.svg`: original `vector/bico-mark-v2.svg`, for branding and
  dark surfaces. Bico is BotConnector's mascot; the product is Switchboard.

No image was regenerated or modified. The console uses the compact mark in both
themes to fit the Harness-style welcome layout. The full hero remains available
for light surfaces. Decorative marks have empty alternative text.
