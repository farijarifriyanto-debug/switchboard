## P2 -> diperbaiki

- Trace JSONL mode 0600 + docstring jujur soal isi tool output (`src/services/trace.ts`).
- CSP pada console web (`src/plugins/web.ts` staticFile).
- DNS-rebind: `guardedFetch` berbasis `node:http/https` dengan `guardedLookup` yang menolak jawaban DNS privat saat connect (literal IP dicek langsung; abort ikut memutus body stream) di `src/services/netguard.ts`, dipakai `tools-web.ts`; tanpa dependensi baru — undici batal dipakai karena undici 8 butuh Node >=22 sedangkan CI menguji Node 20. Tes `ENETGUARD` + penolakan literal IP di `test-netguard.mjs`.
- Discord `connectOnce` timeout handshake 30 dtk, dibersihkan saat READY/RESUMED.
- `providers.json`/`credentials.json` korup: tulis ditolak 409 dengan hint pemulihan; baca tetap jalan; tes di `test-providers.mjs`.
- Path POSIX: updater pakai XDG_CONFIG_HOME; Local Core manager memakai `platform-paths.cjs` Core sendiri (kontrak sama dengan `bin/botconnector.mjs`).
- Polling approval panel: 20 kegagalan beruntun (~10 dtk) menampilkan status+note jujur.
- Mode Manual/Auto/Skip di Cloud standalone: ekstensi memiliki mode sendiri bila tak ada server; error select tampil via `note`, composer disinkronkan.
- Fetch gateway/katalog Cloud: timeout 120 dtk (`AbortSignal.any`+`timeout`), pesan error jujur.
- Tautan onboarding "Preview setup" -> `releases/latest` (bukan v0.4.0).
- `ci.yml` job test `timeout-minutes: 30`.
- AGENTS.md status rilis basi dihapus (angka versi hanya di `docs/release-status.md`); bukti ZIP rilis menunjuk aset GitHub Release, bukan path lokal.
- Kartu approval web console tidak lagi hilang saat POST gagal (`web/app.js`).
